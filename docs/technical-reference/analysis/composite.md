# Composite Analysis

[<- Previous: Univariate Analysis](univariate.md) | [Back to Index](../index.md) | [Next: Bivariate Analysis ->](bivariate.md)

`CompositeAnalysis` is documented with the mathematical treatments of model averaging, mixture composition, and competing risks in [Composite Distributions and Model Averaging](../distributions/composite.md).

That chapter is the canonical reference for:

- `CompositeType` and `AverageMethod`;
- AIC, BIC, DIC, WAIC, LOOIC, equal, and RMSE weighting;
- posterior-realization alignment and uncertainty propagation;
- mixture and competing-risk interpretation;
- validation, failure behavior, and cancellation;
- analytical, R `mistr`, correlation-orthant, and three-child Cartesian-posterior verification; and
- the compile-checked C# workflow.

This page remains as a stable landing URL for existing links. It does not define a separate likelihood or estimation method. Nine of ten Phase 4 recovery-supplement methods pass focused execution; the extreme-tail inversion finding keeps the supplement open. Results are documented in the canonical chapter and [Composite Verification](../../verification/composite.md).
