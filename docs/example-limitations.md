# Example limitations and source provenance

The saved projects are teaching records. A populated curve or completed calculation does not establish convergence, source completeness or engineering suitability. The tutorials retain the recorded data, settings and results, including the limitations below. Inspect the linked example before transferring its assumptions to another study.

| [GHCN Paradise snowfall](../examples/1-time-series-data/2-ghcn-download/ghcn-download-example.md) | All 38 nonzero saved snowfall values are one-tenth of the NOAA magnitude after conversion to inches. The downloader applied the precipitation conversion to a variable with different source units. The tutorial preserves and discloses the original values; they are not correct snowfall magnitudes. |

The Python tutorial overlays the original 25 probability/curve/bound rows on the observations. It does not convert parameters or ensembles, interpolate a curve or refit the analysis. Preserve a copy before changing or rerunning this legacy analysis. |

## Snowfall source comparison

The snowfall finding uses the [NOAA daily format specification](https://www.ncei.noaa.gov/pub/data/ghcn/daily/readme.txt) and [station file](https://www.ncei.noaa.gov/pub/data/ghcn/daily/all/USC00046685.dly), retrieved on 25 September 2026. NOAA defines PRCP in tenths of millimetres and SNOW in millimetres. All 38 matched nonzero saved snowfall values equal the source SNOW integer divided by 254; conversion to inches requires division by 25.4.

## Saved-result display and provenance

The time-series covariate-loading defect is resolved in v2.0.1: project open, copy and undo preserve the saved coefficient vector and priors. The saved Multiple Linear Regression model restores residual RMS 0.341147; the former loading path produced 0.660229. Older Python figures explicitly used saved coefficients with the existing residual method. Their capture provenance remains distinct from a fresh app capture.

The [metadata audit](../examples/metadata-audit.json) records a historical description-edit transaction for 32 projects, with before/after hashes and the documented ABOM test-row removal and Back Creek tree restoration. It does not certify every current project byte: later project changes can differ from those recorded after-hashes. The [figure manifest](../examples/figure-manifest.json) retains each Python figure's original capture source and output hashes; the [screenshot manifest](../examples/screenshot-manifest.json) separately identifies the native captures and their protected inputs. A hash difference is not permission to replace a saved result or silently relabel an older figure.
